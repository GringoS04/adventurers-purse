# Adventurer's Purse

An interactive coin purse for tabletop RPGs. Count coins, slide to pay, and let the GM hand out treasure. Everything runs in one file, `index.html`, with no server.

## Put it online with GitHub Pages

1. Create a new repository on GitHub, for example `adventurers-purse`.
2. Click **Add file → Upload files** and upload `index.html` (and this README if you like). Commit.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to *Deploy from a branch*, pick the `main` branch and the `/ (root)` folder, then **Save**.
5. After a minute or two, your purse is live at `https://<your-username>.github.io/adventurers-purse/`.

To update it later, upload a new `index.html` over the old one.

## Good to know

- The purse saves itself in the browser it runs in. Each phone or browser has its own table.
- Use **Save & load** to make a save code or a save file after each session, and to move a table to another device.
- The online address and the claude.ai version are separate: tables don't carry over between them, except through a save code or file.
- You can also open `index.html` straight from your computer by double-clicking it.
